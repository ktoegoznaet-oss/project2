# Как открыть ваш сайт — инструкция для начинающих

## Способ 1: Самый простой (Windows)

1. Откройте **Проводник** (жёлтая папка на панели задач внизу экрана)
2. Найдите папку с проектом, в ней будет файл **index.html**
3. **Дважды кликните** по файлу `index.html`
4. Сайт откроется в вашем браузере (Chrome, Яндекс.Браузер, Edge и т.д.)

Готово! Вы увидите свой сайт.

---

## Способ 2: Самый простой (Mac)

1. Откройте **Finder** (иконка с улыбающимся лицом в доке)
2. Найдите папку с проектом, в ней будет файл **index.html**
3. **Дважды кликните** по файлу `index.html`
4. Сайт откроется в Safari или другом браузере

---

## Как скачать файлы сайта

Ваш сайт состоит из **3 файлов**. Все три должны лежать в одной папке:

```
📁 Мой сайт/
   📄 index.html    ← главная страница
   📄 styles.css    ← внешний вид (цвета, шрифты, отступы)
   📄 script.js     ← кнопки, формы, анимации
```

**Важно:** Все три файла должны быть в одной папке. Если какой-то файл потеряется — сайт будет выглядеть криво или кнопки не будут работать.

## Как разместить сайт в интернете (чтобы клиенты могли его видеть)

Пока сайт видите только вы на своём компьютере. Чтобы он был доступен всем, нужен **хостинг**. Вот самые простые варианты:

### Вариант А: Бесплатный хостинг на GitHub Pages

1. Зайдите на https://github.com и создайте аккаунт (если ещё нет)
2. Нажмите зелёную кнопку **New** (создать репозиторий)
3. Назовите его, например, `fibrodom`
4. Загрузите туда все 3 файла (кнопка **Upload files**)
5. Зайдите в **Settings** → **Pages**
6. В разделе **Source** выберите **main** и нажмите **Save**
7. Через пару минут сайт будет доступен по адресу:
   `https://ваш-логин.github.io/fibrodom/`

### Вариант Б: Платный хостинг (для серьёзного использования)

Если хотите свой домен (например, fibrodom.ru):

1. Купите домен на **reg.ru**, **timeweb.com** или **beget.com** (~200-500 руб/год)
2. Купите хостинг там же (~100-300 руб/месяц)
3. Загрузите 3 файла в папку `public_html` через панель управления хостинга
4. Сайт станет доступен по вашему домену

## Как поменять данные на сайте

Чтобы заменить заглушки (телефон, адрес, цены) на реальные данные:

1. Кликните правой кнопкой мыши по файлу `index.html`
2. Выберите **Открыть с помощью** → **Блокнот** (Windows) или **TextEdit** (Mac)
3. Используйте поиск: нажмите **Ctrl+H** (Windows) или **Cmd+H** (Mac)
4. Замените:

| Что искать             | На что заменить        |
|------------------------|------------------------|
| `+7 (000) 123-45-67`  | Ваш реальный телефон   |
| `+70001234567`         | Ваш телефон без пробелов |
| `info@fibrodom.ru`     | Ваш реальный email     |
| `ваш город, ул. Промышленная, д. 1` | Ваш реальный адрес |
| `820 000 ₽`           | Ваша реальная цена     |
| `1 480 000 ₽`         | Ваша реальная цена     |
| `1 120 000 ₽`         | Ваша реальная цена     |

5. Сохраните файл: **Ctrl+S** (Windows) или **Cmd+S** (Mac)
6. Обновите страницу в браузере: **F5** или **Ctrl+R**

## Если что-то не работает

- **Сайт выглядит как голый текст без дизайна** → файл `styles.css` не в той же папке, что `index.html`
- **Кнопки не работают** → файл `script.js` не в той же папке
- **Буквы отображаются кракозябрами** → откройте файл в браузере Chrome или Яндекс.Браузер
